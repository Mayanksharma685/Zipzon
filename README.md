# ZipZon - GenZ Fashion E-Commerce Mobile Application

ZipZon is a GenZ-focused fashion e-commerce mobile application built to provide a seamless shopping experience with secure authentication, product management, cloud-based media handling, and online payment integration. The application follows a full-stack architecture where the React Native mobile client communicates with a Node.js backend through REST APIs.

## 🚀 Features

### User Features
- Secure user authentication and authorization using Clerk
- Browse and explore fashion products
- Product details and category-based browsing
- Add products to cart
- Secure checkout workflow
- Online payments using Stripe
- User profile management

### Backend Features
- RESTful APIs built using Node.js and Express.js
- MongoDB-based data management
- Secure API handling for users, products, and transactions
- Cloud image storage and optimization using Cloudinary
- Integrated Stripe payment workflow
- Backend deployed on Vercel

### Mobile Application
- Built using React Native with Expo
- Cross-platform mobile experience
- Responsive and user-friendly interface
- Optimized navigation and smooth user interactions

## 🛠️ Tech Stack

**Frontend:** React Native, Expo, TypeScript  
**Backend:** Node.js, Express.js, REST APIs  
**Database:** MongoDB  
**Authentication:** Clerk  
**Payments:** Stripe  
**Media Management:** Cloudinary  
**Deployment:** Vercel  

## 🏗️ Architecture

React Native (Expo Mobile App)  
↓  
REST APIs  
↓  
Node.js + Express.js Backend  
↓  
MongoDB | Stripe | Cloudinary | Clerk Authentication  

## 🔐 Security & Optimization

- Implemented secure authentication using Clerk
- Protected backend API routes
- Managed sensitive credentials using environment variables
- Integrated secure payment processing with Stripe
- Optimized image handling through Cloudinary
